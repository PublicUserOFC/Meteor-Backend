# Burbank Font

Place the Burbank Big Condensed Bold font file here as `burbank-big-condensed-bold.otf`.

The shop image generator will use this font if available. If the font is not found, it will fall back to Arial.

## Where to get the font

You can find the Burbank font from:
- Fortnite game files
- Font repositories that have Fortnite fonts
- The Neodyme repository may have it included

The font file should be named exactly: `burbank-big-condensed-bold.otf`
